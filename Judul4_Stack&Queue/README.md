# Sistem Antrian Digital Warung Mak Enah
## Deskripsi Singkat
Program dibuat untuk mengimplementasikan antrian  di  sebuah warung bernama Warung Mak Enah. Tamu akan mendapatkan meja dan giliran, dengan cukup mendaftar ke bagian kasir yang nantinya akan dicatat oleh kasir. Lalu akan dipanggil sesuai urutan kedatangan.
